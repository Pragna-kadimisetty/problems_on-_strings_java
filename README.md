1. Find the Length of a String

Description: Takes input from the user and prints the length of the string.
Key Method: length()

String str = "Hello";
int length = str.length();

2. Convert String to Uppercase and Lowercase

Description: Converts user input string to uppercase and lowercase.
Key Methods: toUpperCase(), toLowerCase()

3. Check if Both Strings Are Equal

Description: Compares two user-input strings for equality.
Key Method: equals()
Note: Case-sensitive comparison.

4. Count Words in a String

Description: Counts the number of words in the input string.
Key Methods: trim(), split("\\s+")

5. Check if a String Contains a Word

Description: Checks if a specific word exists in the input string.
Key Method: contains()

6. Concatenate Two Strings

Description: Concatenates two strings entered by the user.
Key Method: concat() or + operator

7. Reverse a String

Description: Reverses the user input string using a loop.

8. Check Palindrome

Description: Checks if a string reads the same forwards and backwards.
Logic: Compare the original string with its reversed version using equals()

9. Count Uppercase and Lowercase Letters

Description: Counts the number of uppercase and lowercase letters in a string.
Key Methods: Character.isUpperCase(), Character.isLowerCase()

10. Count Special Characters

Description: Counts characters that are not letters or digits in a string.
Key Method: Character.isLetterOrDigit()
